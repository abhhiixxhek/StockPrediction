# Stock Analysis and Prediction App

This project is a Streamlit application designed for comprehensive stock market analysis. It allows users to visualize historical stock data, apply various technical indicators, generate AI-driven trading insights, and predict future stock trends using machine learning models.

## Features

*   **Comprehensive Data Visualization**: View historical stock data (Open, High, Low, Close, Volume) with interactive candlestick charts.
*   **Technical Indicators**: Apply and customize a wide range of technical indicators, including:
    *   Simple Moving Averages (SMA)
    *   Exponential Moving Averages (EMA)
    *   Relative Strength Index (RSI)
    *   Moving Average Convergence Divergence (MACD)
    *   Bollinger Bands (BB)
*   **AI-Powered Insights**: Leverage Google's Gemini-2.0-Flash model to generate qualitative insights, sentiment analysis, and buy/hold/sell recommendations based on technical indicator summaries and chart patterns.
*   **Data Refresh Functionality**: Update stock data for NIFTY 50 constituents directly from Yahoo Finance using a dedicated script (`main1.py`).
*   **Stock Prediction**: (Future capability) The application is structured to incorporate predictive models (ARIMA, LSTM) found in the `models/` directory for forecasting stock prices.
*   **Multi-Page Interface**: Organized into sections for analysis, prediction (via `pages/predict.py`), and data management.

## Project Structure

The project is organized as follows:

```
.
├── main.py             # Main Streamlit application for stock analysis and AI insights
├── main1.py            # Streamlit application with data refresh functionality for NIFTY 50 stocks
├── requirements.txt    # Python dependencies for the project
├── stock-env/          # Directory for the Python virtual environment (named 'stock-env')
├── yahoostockdata/     # Stores cached/downloaded stock data as CSV files
├── pages/              # Contains additional Streamlit pages
│   └── predict.py      # Page dedicated to stock prediction functionalities
├── models/             # Contains pre-trained machine learning models
│   ├── arima.joblib

│   └── scalerhybrid.joblib
├── utils/              # Utility scripts
│   ├── datafetcher.py  # (Likely) Helper functions for fetching data
│   └── insights.py     # (Likely) Helper functions for generating insights
├── .gitignore          # Specifies intentionally untracked files that Git should ignore

```
*   **`main.py`**: The primary entry point for the Streamlit application. It handles data loading, technical indicator calculations, chart displays, and interaction with the Gemini AI for insights.
*   **`main1.py`**: A secondary Streamlit application specifically designed to refresh the stock data from Yahoo Finance. It fetches data for NIFTY 50 stocks and saves them into the `yahoostockdata/` directory.
*   **`requirements.txt`**: Lists all Python packages required to run the project.
*   **`stock-env/`**: This directory is intended to house the project's Python virtual environment, named `stock-env`.
*   **`yahoostockdata/`**: Contains CSV files of historical stock data, downloaded from Yahoo Finance. `main1.py` populates this directory.
*   **`pages/predict.py`**: A Streamlit page likely intended for displaying stock price predictions generated by the machine learning models.
*   **`models/`**: This directory stores trained machine learning models (like ARIMA, LSTM) and associated scalers, which can be used for predicting stock trends.
*   **`utils/`**: Contains Python scripts with helper functions, possibly for data fetching (`datafetcher.py`) and generating analytical insights (`insights.py`).

## Setup and Usage

Follow these steps to set up and run the project:

1.  **Clone the Repository:**
    ```bash
    git clone <repository-url>
    cd <repository-directory>
    ```

2.  **Create and Activate Virtual Environment:**
    It's recommended to use a virtual environment. The designated name for this project's environment is `stock-env`.
    ```bash
    python -m venv stock-env
    ```
    Activate the environment:
    *   On Windows:
        ```bash
        .\stock-env\Scripts\activate
        ```
    *   On macOS/Linux:
        ```bash
        source stock-env/bin/activate
        ```

3.  **Install Dependencies:**
    Install all required packages using the `requirements.txt` file:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set Up Environment Variables:**
    The application uses Google's Gemini API for AI-powered insights. You'll need to set up an API key.
    *   Create a file named `.env` in the root directory of the project.
    *   Add your Google API key to this file:
        ```
        GOOGLE_API_KEY="YOUR_GOOGLE_API_KEY"
        ```
    Replace `"YOUR_GOOGLE_API_KEY"` with your actual API key.

5.  **Run the Data Refresh Application (Optional but Recommended First):**
    To ensure you have the latest stock data, run `main1.py`. This script will fetch data for NIFTY 50 stocks and store it in the `yahoostockdata` directory.
    ```bash
    streamlit run main1.py
    ```
    Open your browser and navigate to the provided local URL. Use the "Refresh Stock Data" button in the sidebar.

6.  **Run the Main Application:**
    Once the data is populated, you can run the main stock analysis application:
    ```bash
    streamlit run main.py
    ```
    Open your browser and navigate to the provided local URL to start analyzing stocks.

7.  **Access Prediction Page:**
    The application may have a separate page for predictions. If running, it's typically accessible via a navigation menu provided by Streamlit when multiple pages are present in the `pages` directory.

## A Note on Data

*   The application is primarily designed to work with historical data for the NIFTY 50 stocks, sourced from Yahoo Finance.
*   The `main1.py` script is responsible for fetching and refreshing this data. It stores the data in CSV files within the `yahoostockdata/` directory.
*   It is recommended to run `main1.py` periodically to keep the local data store up-to-date for accurate analysis.
*   The date range for data fetching in `main1.py` is set to the last 5 years.
